## 문서 읽는 법

### 사용 주체 약어

| 약어 | 사용자 |
|---|---|
| WK | 장애인 근로자 |
| CM | 기업 담당자 |
| VM | 브이드림 매니저 |
| SA | 시스템관리자 |
| SYS | 시스템 처리 (요청 처리 중 자동으로 일어나는 동작. 스케줄러·배치는 없음) |
| 방문자 | 로그인 전 랜딩 페이지 방문자 (인사 담당자 등) |

### 화면 약어

| 약어 | 화면 |
|---|---|
| MOB | 근로자 모바일 화면 (`/m`). 데스크톱에서는 휴대폰 프레임 안에 표시 |
| WEB | 관리자 화면 (`/admin`, CM·VM 공용) |
| SYS | 시스템관리 화면 (`/system`) |
| LAND | 랜딩 페이지 (`/`) |
| API | 백엔드 API (화면 없이 서버에서만 처리) |

### 우선순위

| 구분 | 의미 |
|---|---|
| 필수 | 2주 안에 반드시 포함 |
| 권장 | 시간이 남으면 포함. 개발 계획 5장의 후순위 조정 대상 |

### 기능 ID 규칙

`카테고리코드-일련번호` 형식. 예: `ATTD-003`

| 코드 | 카테고리 |
|---|---|
| AUTH | 인증 및 계정 |
| NOTI | 알림 |
| ANNC | 공지사항 |
| SYSM | 시스템관리 및 데모 운영 |
| RESM | 근로자 이력서 |
| REGI | 구직 등록 |
| JOBP | 채용 공고 |
| APPL | 입사지원 및 채용 진행 |
| EMPL | 재직 및 근로계약 |
| RESG | 퇴사 |
| ATTD | 근태관리 |
| LEAV | 휴가관리 |
| TASK | 업무 배정 |
| WLOG | 업무일지 |
| CNSL | 브이드림 상담보고서 |
| MESG | 쪽지 |
| EMRP | 월간 장애인 고용 리포트 |
| DASH | 대시보드 |
| DEMO | 랜딩 페이지 및 데모 체험 |
| ACCS | 접근성 및 UI |

## 1. 인증 및 계정 (AUTH)

| ID | 기능명 | 상세 설명 | 주체 | 화면 | 우선순위 | 비고 |
|---|---|---|---|---|---|---|
| AUTH-001 | 로그인 | 아이디와 비밀번호로 로그인한다. 성공 시 액세스 토큰(24시간)을 발급한다. 로그인 후 역할에 맞는 화면(`/m`, `/admin`, `/system`)으로 이동한다 | 전체 | MOB, WEB, SYS | 필수 | JWT |
| AUTH-002 | 데모 로그인 | 역할을 지정해 호출하면 해당 역할의 데모 계정으로 로그인된다. 비밀번호 입력 없음 | 방문자 | LAND, API | 필수 | DEMO-002에서 사용 |
| AUTH-003 | 비밀번호 변경 | 현재 비밀번호 확인 후 새 비밀번호로 변경한다. 최소 8자. 데모 계정은 변경 불가 | 전체 | MOB, WEB, SYS | 권장 | |
| AUTH-004 | 로그아웃 | 클라이언트의 토큰을 삭제하고 랜딩 페이지로 이동한다 | 전체 | MOB, WEB, SYS | 필수 | 서버 상태 없음 |
| AUTH-005 | 내 정보 조회 및 수정 | 이름, 휴대폰번호, 이메일을 조회하고 수정한다. 아이디와 역할, 소속은 수정 불가 | 전체 | MOB, WEB, SYS | 필수 | WK의 기본정보는 이력서와 공유 |
| AUTH-006 | 비활성 계정 차단 | 비활성화되거나 삭제된 계정은 로그인이 거부되고 기존 토큰도 거부된다 | SYS | API | 필수 | |
| AUTH-007 | 역할별 경로 보호 | 역할에 맞지 않는 경로에 접근하면 자기 역할의 홈으로 보낸다. 로그인하지 않으면 랜딩 페이지로 보낸다 | SYS | MOB, WEB, SYS | 필수 | 라우트 가드 |

## 17. 월간 장애인 고용 리포트 (EMRP)
