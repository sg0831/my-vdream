## 문서 읽는 법

### 사용 주체 약어

| 약어 | 사용자 |
|---|---|
| WK | 장애인 근로자 |
| CM | 기업 담당자 |
| VM | 브이드림 매니저 |
| SA | 시스템관리자 |
| SYS | 시스템 자동 처리 (배치, 트리거) |

### 플랫폼 약어

| 약어 | 플랫폼 |
|---|---|
| APP | 근로자 모바일 앱 (iOS, Android) |
| WEB | 관리자 웹 (CM, VM 공용) |
| SYS | 시스템관리자 웹 |
| API | 백엔드 API 서버 (클라이언트 화면 없이 서버에서만 처리) |

### 우선순위

| 구분 | 의미 |
|---|---|
| 필수 | 1차 출시에 반드시 포함 |
| 권장 | 1차 출시에 포함하되 일정상 후순위 조정 가능 |

`카테고리코드-일련번호` 형식. 예: `ATTD-003`

| AUTH | 인증 및 계정 |

| SYSM | 시스템관리 |
| RESM | 근로자 이력서 |

| JOBP | 채용 공고 |

| RESG | 퇴사 |

| TASK | 업무 배정 |

## 1. 인증 및 계정 (AUTH)
