## 문서 읽는 법

### 사용 주체 약어

| 약어 | 사용자 |
|---|---|
| HK | 헬스키퍼 근로자 |
| CM | 기업 헬스키퍼 관리 담당자 |
| WM | 장애인복지관 헬스키퍼 관리자 |
| SA | 시스템관리자 |
| SYS | 시스템 자동 처리 (배치, 트리거) |

### 플랫폼 약어

| 약어 | 플랫폼 |
|---|---|
| APP | 헬스키퍼 모바일 앱 (iOS, Android) |
| WEB | 관리자 웹 (CM, WM 공용) |
| SYS | 시스템관리자 웹 |
| API | 백엔드 API 서버 (클라이언트 화면 없이 서버에서만 처리) |

### 우선순위

| 구분 | 의미 |
|---|---|
| 필수 | 1차 출시에 반드시 포함 |
| 권장 | 1차 출시에 포함하되 일정상 후순위 조정 가능 |

`카테고리코드-일련번호` 형식. 예: `ATTD-003`

| 코드 | 카테고리 |
|---|---|
| AUTH | 인증 및 계정 |
| NOTI | 알림 |
| ANNC | 공지사항 |
| SYSM | 시스템관리 |
| RESM | 헬스키퍼 이력서 |
| REGI | 복지관 구직 등록 |
| JOBP | 채용 공고 |
| APPL | 입사지원 및 채용 진행 |
| EMPL | 재직 및 근로계약 |
| RESG | 퇴사 |
| ATTD | 근태관리 |
| LEAV | 휴가관리 |
| RCPT | 피술자 관리 |
| TRTM | 시술 일정, 시술 장소 및 시술 일지 |

## 1. 인증 및 계정 (AUTH)

| ID | 기능명 | 상세 설명 | 주체 | 플랫폼 | 우선순위 | 비고 |
|---|---|---|---|---|---|---|
| AUTH-001 | 로그인 | 아이디와 비밀번호로 로그인한다. 성공 시 액세스 토큰과 리프레시 토큰을 발급한다. 역할에 맞지 않는 플랫폼에서는 로그인을 거부한다 (예: CM이 앱 로그인 시도) | 전체 | APP, WEB, SYS | 필수 | JWT |

| AUTH-003 | 비밀번호 변경 | 현재 비밀번호 확인 후 새 비밀번호로 변경한다. 최소 8자, 영문과 숫자 포함 | 전체 | APP, WEB, SYS | 필수 | |
| AUTH-004 | 토큰 갱신 | 리프레시 토큰으로 액세스 토큰을 재발급한다. 리프레시 토큰은 회전(rotation)하며 서버에 해시로 저장한다 | 전체 | API | 필수 | |
| AUTH-005 | 로그아웃 | 현재 기기의 리프레시 토큰과 푸시 토큰을 무효화한다 | 전체 | APP, WEB, SYS | 필수 | |
| AUTH-006 | 생체인증 재로그인 | 한 번 로그인한 뒤 앱 재진입 시 Face ID, Touch ID, 지문 인증으로 저장된 토큰을 열어 자동 로그인한다. 생체인증 미지원 기기는 비밀번호 로그인으로 대체 | HK | APP | 필수 | 안전 저장소 사용 |
| AUTH-007 | 내 정보 조회 및 수정 | 이름, 휴대폰번호, 이메일을 조회하고 수정한다. 아이디와 역할, 소속은 수정 불가 | 전체 | APP, WEB, SYS | 필수 | HK의 기본정보는 이력서와 공유 |
| AUTH-008 | 비활성 계정 차단 | 비활성화되거나 삭제된 계정은 로그인과 토큰 갱신이 모두 거부된다 | SYS | API | 필수 | |
| AUTH-009 | 로그인 실패 제한 | 연속 5회 실패 시 10분간 로그인을 잠근다 | SYS | API | 권장 | |

| 상태 | 코드 | 설명 |
|---|---|---|
| 정상 | NORMAL | 정시 출근, 정상 퇴근 |
| 지각 | LATE | 소정 근로 시작 시각 이후 출근 |
| 조퇴 | EARLY_LEAVE | 마지막 세트 종료 시각 이전 퇴근 |
| 지각 및 조퇴 | LATE_EARLY_LEAVE | 둘 다 해당 |
| 결근 | ABSENT | 근무일에 출근 기록과 승인 휴가 없음 |
| 휴가 | ON_LEAVE | 승인된 전일 휴가 |

반차는 근태 상태가 아니라 별도의 반차 구분(오전, 오후) 컬럼으로 기록한다. 반차 날의 상태는 출퇴근 판정 결과를 따른다.
